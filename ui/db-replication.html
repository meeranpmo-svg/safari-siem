Replication & Data Guard

Data Guard and GoldenGate are monitored with the read-only account. Next to them, the platform's own engines: Data Verify (compare a source and a target table row by row - only the keys of rows that differ are kept), Change Stream (who changed what in the database, from the redo with LogMiner - no row values) and Replication to a reporting / analytics target. Each engine uses its own dedicated account; the replication writes, so it needs a second person's approval, stops on any conflict and is not a substitute for Data Guard as the DR path.
