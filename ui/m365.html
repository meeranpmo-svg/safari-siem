🧭 One-time setup in Microsoft Entra about 5 minutes

  1. Entra admin center → App registrations → New registration, name it e.g. {{org.short}} SIEM, single tenant, no redirect URI.
  2. Copy the Directory (tenant) ID and the Application (client) ID from the app's Overview into the form above.
  3. Certificates & secrets → New client secret (12 or 24 months), copy the Value (not the Secret ID) into the form. Note the expiry date for renewal.
  4. API permissions → Add a permission → Microsoft Graph → Application permissions: add the permissions in the table above. For the Exchange Online audit log also add Office 365 Management APIs → Application → ActivityFeed.Read.
  5. Press Grant admin consent for …, then Save and Sync now here. Each row in the table turns green as soon as its permission works.
  6. The SIEM server needs outbound HTTPS to login.microsoftonline.com, graph.microsoft.com and (audit log) manage.office.com.

All permissions are read-only. Sign-in logs and risky users also need an Entra ID P1/P2 licence in the tenant.
