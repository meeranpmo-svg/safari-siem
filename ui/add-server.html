Administrators only

Adding a server stores a login and scans the network, so it needs the System Admin role.

1 · What are you adding?

Nothing is installed on the server; discovery only reads.

Adding many devices? Use Network Discovery (IP range, subnets or a CSV list).

Discovery reads the device over SNMP (read-only): name, model, serial, firmware, location and its LLDP / CDP neighbours. Nothing is changed on the device.

2 · SNMP (read-only)

Use a read-only community or a read-only SNMP v3 user. The secret is stored encrypted and never shown again. UDP 161 must be open from the platform server ({{org.platform_addr}}) to the device.

2 · How to log in (read-only)

A normal user is enough; never root. The password is stored encrypted, only used for this scan and never shown again.

Use a private key instead of a password
Web addresses (optional): applications, management console (ILOM / iLO / iDRAC, firewall / switch web GUI)
Saved with the server in IT Asset Management. No logins in the address - only where to reach it.
Optional: SNMP (better model / OS detection)
Optional: Oracle database on this server (edition, version, databases)

Use the read-only SENTRA_MON account (agents/oracle/create-monitor-user.sql). Leave the service name empty to skip. Port: the listener port this site uses - discovery looks for the database on it.

Optional: SQL Server on this server (edition, version, databases)

Leave the login empty to skip. A named instance listens on its own port - give that port (SQL Server Configuration Manager → TCP/IP → IPAll).

3 · Approve the scan

Every scan needs this approval once (the safety gate). It is recorded with your name.

2 · The Windows server or PC

Windows is not scanned over the network from here. It joins the platform in one of three ways - use one, or all three:

  1. Register it now (above): the record appears in IT Asset Management at once; a Windows server with an IP is picked up by the AI Windows Administrator automatically.
  2. Install the asset agent - nothing to install besides one PowerShell script; it fills hardware, software and patches and keeps them current, also from project sites off the network: Agents & Downloads →
  3. Every computer from Active Directory at once - a read-only LDAPS account lists all servers and workstations of the domain, by OU: Asset Discovery → a scope with the Active Directory method →

Security events from this server go to the SIEM with the Windows agent (same page, "SIEM agent for Windows").
