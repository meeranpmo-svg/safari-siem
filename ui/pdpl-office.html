Privacy Office

PDPL is run here as its own organisation: the DPO, the privacy committee, an owner for each PDPL function, a data steward and a privacy champion in each department, and a data owner for each system. Every finding the PDPL registers raise, and every recurring duty that falls due, becomes a task for a named person, with a deadline. Overdue tasks go to the DPO, then to the committee chair. A task closes only when the registers show it is fixed: a task marked done is re-checked against the registers every 30 minutes, closed as verified when the finding is gone, and reopened and escalated when it is still there after the re-check period.
