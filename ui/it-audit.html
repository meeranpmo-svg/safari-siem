Network configuration changes

Every configuration change the firewalls, routers and switches logged to the SIEM, matched against approved change plans for the same device (approved before the change, within 3 days). A change with no approved plan needs an explanation for the auditor.

Privileged and sensitive activity

Administrator actions, credential and configuration changes in the SIEM, and every denied access attempt.

User access review

People who used the SIEM and portal functions in the period, their role and last activity. Review that each role is still needed; administrators with no activity for 30 days should be reviewed.

Change plans

Every planned change - network devices, servers, Kaspersky and Zscaler - with who proposed, who approved and the validation result after the change.
