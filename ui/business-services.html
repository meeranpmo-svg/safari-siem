Business Services

Every server, and what runs on it: Oracle, SQL Server, MySQL, PostgreSQL and other databases, IIS / Apache / nginx, Tomcat / WebLogic / WebSphere, SAP, Exchange, Active Directory and message queues. It is found automatically from Asset Discovery, the installed-software list, the database logins, a read-only SSH look (trusted host keys only) and a network probe without login (only inside scanned scopes whose safety checklist is complete). A port alone is shown as possible; a banner, process, service, installed product or login makes it confirmed. Databases and applications are proposed as business-critical - an administrator confirms. A server nothing could read says not checked and why.
