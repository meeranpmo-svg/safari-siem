Lines are rebuilt from the inventory each time this page is read: licences expiring by year end, warranties ending, systems reaching end of support, storage above the warning level, and last year's pending items. An amount comes only from a recorded cost or a standard cost you set - otherwise the line says price needed. Within each envelope lines are ranked Must → Should → Could, then by due date; does not fit means the running total passes the envelope at that line. Approve, defer or reject each line - every decision is kept in the audit log.

New requirement or project

For needs the inventory cannot know about: new systems, projects, consultancy, training, compliance work.

Edit the budget in Excel

  1. - one row per line, with its Line ID.
  2. In Excel change Amount, Priority (must / should / could), Status (proposed / approved / deferred / rejected) and Note on any line; Title, Envelope, Type and Due too on requirements added by hand. Add a new requirement as a new row with the Line ID empty. Keep the Line ID column as it is; deferring or rejecting needs a Note.
  3. Choose the saved file here. Every change and every row that needs fixing is shown first - nothing is saved until an administrator presses Apply, and then all of it or nothing. Each change is kept in the audit log with the file it came from.

Last year's budget

Choose last year's budget as an Excel workbook (.xlsx) or a CSV file - the first worksheet is read. Recognised columns (any order, first row = headings): Item / Description, Budget (IT Operations / Cyber Security), Category (Infrastructure / Applications / Security), Type (CAPEX / OPEX), Approved, Spent / Actual, Status (Pending, In progress, Committed, Completed, Cancelled), Vendor.

Pending, in-progress and committed lines carry over to next year with what is left (approved minus spent). Completed and cancelled lines do not. Importing again replaces the previous import.

Price suggestions for lines marked "price needed"

Learned from this organisation's own purchase orders and asset purchase costs (same model, else same type, else the same product), median and middle half, inflated to the fiscal year at the budget's inflation rate. An administrator accepts a price - it goes through the IT Budget's own decision and is audited.

Best budget mix within each envelope

An exact selection (0/1 knapsack) over value = priority (must 100, should 40, could 10) × due in the first half (+30 %) × end of life or security (+20 %). "Must" lines are always in. A proposal: nothing changes until an administrator decides each line on the Budget lines tab.

Envelopes and standard costs

Standard costs are used only when the inventory has no purchase cost for an item. Leave a cost empty if you do not know it - those lines then show price needed instead of a guess.
