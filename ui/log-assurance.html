Discovered assets are enrolled into SIEM log collection automatically (servers, network devices, storage, VMs in use). Enrolment only prepares the SIEM: each device still has to be configured to send, and the AI SIEM Engineer keeps a work item open - with the exact configuration - until its logs arrive. "Silent" is judged per class: a firewall quiet for 15 minutes is a problem, an iLO quiet for a day is not. Nothing here changes a device.
