Audit · Data analytics

Audit Analytics

Analyse the whole population - the platform's own records or a file you import - with duplicates, fuzzy duplicates, gaps, Benford's law, strata, ageing, outliers, joins and filters, and draw statistically sized samples. Every run goes into the command log with the dataset's hash, the parameters and the result's hash, so it can be re-performed. A different person reviews it; exceptions are explained or raised as a finding in an audit engagement. Results are indicators to follow up, not proof of wrongdoing. Datasets may hold personal data (PDPL): every view, import and export is recorded.
