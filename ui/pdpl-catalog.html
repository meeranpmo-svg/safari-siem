Every Oracle, SQL Server and PostgreSQL database with a proven read-only login is scanned; SharePoint / OneDrive is read through Microsoft Graph and file shares by the Windows agent on the file server. For databases: column names, comments and row estimates from the dictionary; where the login may read a table, 50 values are tested on the platform server and only the number of matches is kept. No personal data value is stored or shown. An administrator confirms the identifier columns a person can be found by; the search itself runs from a verified data subject request.
