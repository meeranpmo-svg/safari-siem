Non-Human Identities

Every identity that is not a person: Active Directory service accounts and managed service accounts, Entra ID app registrations, this platform's connector and scan credentials, agent keys and API keys, and the AI engineers. Each one needs a named owner, a purpose, a secret that is rotated, no more privilege than its job, and to be removed when it is no longer used. Risks come from what each source reports; a source that is not connected is named below, never read as "none". The platform never disables an account or rotates a secret: decommissioning is requested, approved by an administrator who did not request it, done at the source by a person and recorded - and the register flags a "done" the source contradicts.
