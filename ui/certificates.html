Certificate requests

A certificate is accepted only when it belongs to the request's private key, covers every name asked for and is valid. Private keys stay sealed on the platform; an administrator can export one with a reason (audited).
Phase 3 - installation on Palo Alto and FortiGate. A person proposes installing an issued certificate on a device; a different person who may approve Security changes approves it; it runs (now, or in the maintenance window), and a scan of the endpoint must show the new certificate before it counts as done. The previous certificate stays on the device, and an approver can roll back. Each device's TLS certificate is pinned and its write API key is sealed - never shown again.
