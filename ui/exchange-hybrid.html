Exchange Hybrid Migration

On-premises Exchange to Exchange Online in hybrid mode. The checks below are read from your Exchange servers with the AI Exchange Server Administrator's read-only login. Nothing here changes Exchange or Microsoft 365: for each migration wave the page writes the CSV and the Exchange Online PowerShell, your Exchange admin runs it, and records the outcome here.

The migration, step by step

1. PrepareSupported Exchange update, public certificate, EWS published with MRS Proxy, Entra Connect synchronising.
2. Hybrid Configuration WizardCreates the routing domain, connectors, organization relationship and OAuth. Then move one test mailbox both ways.
3. Pilot waveIT staff first. Check Outlook, mobile, calendar sharing and mail flow both ways.
4. WavesDepartment by department: copy in the background, switch users over in the window.
5. Cut-overWhen every mailbox is in the cloud: MX and Autodiscover to Exchange Online, update SPF.
6. AfterKeep one Exchange server (or the Exchange Management Tools) to manage the users from Active Directory; retire the rest.
