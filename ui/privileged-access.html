Privileged Access

Nobody needs to sit in an admin group all the time. Ask for the group for the hours the work needs, with the reason and the ticket; one of the group's approvers (or an administrator) approves - never the person asking. The platform adds your AD account to the group at the start time and removes it automatically when the time is up, checking the directory both times. Domain / Enterprise / Schema Admins and the other tier-0 groups are not requestable here: they stay with the break-glass procedure.
