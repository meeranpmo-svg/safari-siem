Database Health Statement

When an application team reports "the database is slow": pick the database and the time it happened. The statement checks the database, its server and the network path from the application server, each with the reading behind it, and concludes healthy / database / server / network - or not measurable when there is too little data. Keep it, print it, or route the issue to the team that owns it.

Prepare a statement

The window can be up to 24 hours within the last 30 days; "normal" is the same hours of the previous 7 days. Times are your browser's local time.
