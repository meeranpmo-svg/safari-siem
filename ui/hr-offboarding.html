HR Offboarding

Directory settings
HR records the leaver and the platform reads the account from Active Directory so everyone sees who it is. The line manager confirms the leaving, then an administrator who is neither the requester nor the confirmer approves disabling the account. On the last day (at the hour set in Directory settings, Riyadh time) - or at once for an immediate termination - the platform disables it, replaces its password with one nobody knows, notes the request in its description and moves it to the leavers OU. It never deletes the account and keeps its groups on record. Privileged accounts, accounts on the never-disable list and an account whose employee number does not match are refused: a domain administrator disables those by hand. Hybrid Microsoft 365 sign-in stops at the next directory sync; revoking open sessions and the mailbox stay with the Microsoft 365 administrators.
