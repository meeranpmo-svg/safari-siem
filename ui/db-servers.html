Database Servers

Every server a monitored Oracle database runs on, aligned with its IT asset record, and its operating system read over SSH every 15 minutes: file systems, inodes, memory and swap, CPU load, Oracle instances against /etc/oratab, listeners, clock sync, HugePages / THP, uptime and last patch. The platform only logs in where the SSH host key is one an administrator trusted, with a read-only login - a server it cannot read says why and is never shown as healthy.
