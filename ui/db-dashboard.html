Open problems

Acknowledge = you are on it: no more reminders. Snooze = known and accepted for a while (with a reason). A problem clears by itself when a fresh reading is back within the threshold; a reading that stops arriving keeps it open (marked stale) - it is never cleared silently.

Alert-log errors, last 24 hours

ORA- lines from each database's alert log: the collector agent's tail, or the platform's hourly read of V$DIAG_ALERT_EXT (needs SELECT on it for the monitoring account). The same line read twice counts once. What to check is guidance for the DBA - nothing is run on the database from here. Codes you consider noise can be ignored on the Thresholds tab.

Thresholds

Exceptions per database / tablespace

The most specific rule wins: ORCLPRD/USERS (one tablespace) → */USERS (that tablespace everywhere) → ORCLPRD (the whole database) → the default above. Changing thresholds needs an administrator or the DBA named in Roles & Functions (AI Oracle DBA approver), and a reason; every change is in the audit log.
