Sessions

Blockers first, then by how long they run. Cancel SQL stops only the running statement (the session and its open transaction stay; Oracle 18c+). Kill session ends the session and rolls back its open transaction - an hour of work can take as long to roll back. Both are requests: a different person - an administrator or a DBA approver - approves, and the database re-checks the session (same user, same statement, not a system account) before acting.
