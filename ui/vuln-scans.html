Vulnerability Scans (internal network)

Scans of {{org.short}}'s internal network with Greenbone / OpenVAS. A scan sends probes into the network, so it is a change: it may only cover the internal scan scope an administrator set (private ranges, with exclusions), an operator requests it with a time window and a reason, and a different named person approves it. The platform starts it when the window opens and stops it when the window ends. A finding is fixed only when a later scan of the host no longer reports it.
