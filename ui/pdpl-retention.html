PDPL Art. 18 / Implementing Regulation Art. 19: personal data is kept no longer than needed. Each mapped table gets one read-only count of the rows older than its retention rule, through the Data Catalog's read-only login. Counts only - no row and no personal data value is read, stored or shown. The platform never deletes or changes data: the data owner disposes of the rows in the system and records it here.
