AI Engine

Which model the AI features use: the local model on {{org.short}}'s own AI server, Claude through the Anthropic API, or none. It applies to every AI feature in IT Asset Management and in the SIEM, at once, without a restart. Everything that is not AI (collection, detection, rules, scores, dashboards, approvals) works the same in every mode.

Model

If the gateway needs a key, it is set on the servers only, never on this page: sudo itam-secrets set local_ai_key (IT Asset Management) and local_ai_key in the SIEM's secrets.json (secure-secrets.sh).
Administrators change the AI engine.

Per-feature routing send chosen AI features to a different engine than the model above - e.g. everything touching personal data to the local model, the heavy investigations to Claude

A rule is a feature name (soc.copilot), a group (dfir.* - the feature and everything under it) or * (every feature). The most specific rule wins; a feature with no rule uses the model above. Saved with "Save for both engines".
