Windows servers with the SIEM agent

The SIEM agent (scheduled task SentraAgent) reads the Security, System and Sysmon logs and sends them over HTTPS to the SIEM with its source token. By default it sends once a minute; installed with -Realtime it reads the logs every 5 seconds, so events reach the SIEM within seconds (see SIEM Live Logs). Several servers can share one source; each server appears under Servers reporting once its first events arrive.
