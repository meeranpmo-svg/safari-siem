How an update behaves now

  1. Before sentra-itam restarts, every engine module is loaded in a test process; a file a module needs but nobody installed is copied from the package (preflight).
  2. A page whose API does not answer is named, its cause read from the log, and the update keeps everything else - one page no longer takes the others back with it.
  3. An installer that still rolls back its own module records why, so it shows here.
  4. After the last restart every page API is checked again (final check).
  5. Fix the cause shown above, then run the update again: git pull origin main and update-platform.ps1.
