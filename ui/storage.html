Storage systems

Read-only - nothing on an array can be changed from here. NetApp ONTAP (9.6 or later): the cluster management address and a user with the readonly role for the http application (security login create -user-or-group-name siem-ro -application http -authentication-method password -role readonly). Synology (SA3600 and other DSM 7 models): the DSM address on port 5001 and a dedicated administrators-group account with two-factor sign-in off, allowed only from this server - DSM has no read-only administrator, so the platform only ever calls the read methods. HPE MSA (2060 / 2062 / 2050 / 2052 / 2040 / 1060 / 1050 / 1040 / P2000 G3): a controller management address and a user with the monitor role and the WBI/API interface enabled. Self-signed certificates: Test, then Trust & pin. Read every 30 minutes.
