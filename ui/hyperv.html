Hyper-V Servers

Add Hyper-V hosts

Type the host names (one per line, up to 50). Each host gets its own one-time key, valid for 24 hours, and one command. On the host, open PowerShell as Administrator, paste its command and press Enter. The command downloads the report script from this portal, checks its fingerprint (SHA-256), enrols the host and creates the 15-minute scheduled task. The host sends a read-only report; the portal never logs on to the host.

Use the Windows computer name (run hostname on the host). An IP address works too: once the command has run, the host is shown with the name it reports under.
