Agents & Downloads

Download an agent from the platform, check its fingerprint, connect it with a one-time key - for servers, desktops and the computers at project sites that are not on the company network

How the agents reach the platform

  • Outbound only. Every agent opens an HTTPS connection to on port 443 - it never listens and needs no inbound firewall rule. A computer at a project site connects over the internet or a site VPN.
  • From the internet, publish only /agent/ (asset agents) and /ingest/ (SIEM agents) of the portal - for example a FortiGate virtual IP with a policy that allows HTTPS to those paths only. The rest of the portal stays internal.
  • Certificate: a computer outside the domain does not trust an internal certificate - use a public certificate for the published name, or import the portal certificate on each computer first.
  • Offline: the SIEM agent keeps events on disk while the platform cannot be reached; the asset agent sends a fresh, complete inventory on its next run.
