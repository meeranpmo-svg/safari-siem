Email / Phishing Analysis

Paste the full message source, or open a saved .eml. Outlook: File → Properties → Internet headers (headers only), or drag the message to the desktop and open the file here. OWA: ⋯ → View → View message details. Reported by a user? Ask for it as an attachment so the headers survive. The message is analysed in this browser only - it is not stored and nothing is opened or looked up on the internet. Only the sender domains, link hosts and the origin IP are checked against the SIEM's own indicator lists.
