Power Control

Restart, shut down and start VMware ESXi hosts, VMware VMs, Nutanix AHV hosts and Nutanix VMs - as approved change plans with safety checks, verified by the next collection
Virtualization →AI Virtualization Admin →
This page never powers anything itself. You ask for an action; the platform checks it is safe (the rest of the cluster can carry the running VMs, one Nutanix node at a time, VMware Tools for a clean guest shutdown) and writes the exact steps. An approver who did not ask approves it (a failed check needs the accepted risk in words), an engineer runs the steps and records it here, and the next vCenter / Prism collection verifies the result. Approvals last 24 hours. A powered-off host is started from its iDRAC / iLO / IPMI - the engineer's own login is asked for when the command runs and is never stored.
