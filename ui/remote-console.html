Remote Console

Log in to Windows (Remote Desktop), Linux, Solaris, ESXi, Nutanix and network devices (SSH) from the portal - after another person approves a time-limited request. You type your own account; every gateway session is recorded. Physical servers also open their out-of-band controller (iDRAC / iLO / XClarity) so you can watch a reboot from POST and BIOS to the login screen.

Out-of-band controllers

Record each physical server's iDRAC / iLO / XClarity / BMC address once. Operators then request it like any other console. Only the address is kept - never a controller account or password. The kind is suggested from the vendor; check it.
